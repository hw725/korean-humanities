# 한국학 용어 영문 대역 전거 (terminology authorities)

> 고유명사·제도·개념어의 영문 대역과 로마자 표기를 정할 때 참조하는 외부 전거와
> 사용 규칙. 임의 번역·기억 속 관행보다 **용례 전거**가 우선한다.

## 1순위 전거: 한국학 영문 용어·용례 사전 (AKS Korean Studies Glossary)

한국학중앙연구원이 2005년부터 구축한 대역 용례 사전. 200여 권의 한국학 번역
명저에서 추출한 용례를 수록하며, 항목마다 **한글명(한자명) · 분야/유형/시대 ·
정의 · 문화관광부(RR) 표기 · 매큔-라이샤워(MR) 표기 · 의미역(영문 대역) ·
용례문 · 출전**을 제공한다 — 이 구조가 곧 이 스킬의 설정 축(MR/RR·한자 병기)과
맞물린다.

## 사용 규칙

1. **용례 전거이지 강제 표준이 아니다.** 사전은 「번역되는 다양한 사례」를 모은
   것이라 한 표제어에 복수 의미역이 있을 수 있다 — 출전의 격(학술 번역 명저 우선)과
   문맥 일치로 선택하고, 원고에 처음 쓸 때 선택 근거를 주석·역자주 후보로 남긴다.
2. **로마자는 사용자 설정이 우선하되, 표기값은 사전에서 가져온다** — 사전이 문광부
   (RR)·MR을 병기하므로, 설정이 MR이면 MR 칸을, RR이면 문광부 칸을 그대로 쓴다
   (직접 변환해 만들지 않는다 — ŏ·ŭ 브레베 누락 사고 방지).
3. **웹 조회가 가능한 세션에서는 실조회한다.** 조회 불가 세션에서는 관행 대역을
   쓰되 `unverified` 표기하고, 위 경로에서의 확인을 다음 단계로 남긴다.
4. **기관·대학 공식 영문명은 사전보다 해당 기관 공식 표기가 우선한다**
   (사전 구성 원칙 자체가 그렇다).
5. 사전에 없는 전문용어(신조 개념어 등)는 임의 번역하지 말고 ①로마자 표기 +
   한자 병기 + 짧은 gloss ②기존 영어권 연구의 용례 탐색, 두 경로를 사용자에게
   선택지로 제시한다.
