# 체계적 코퍼스 선별의 게이트 (systematic-review 보조)

> `mode-router.md` §8에서 `systematic-review`를 고른 뒤에만 읽는다. 대상은 文集 코퍼스 구축,
> KCI 동향 대량 조사, 이본 목록처럼 포함/제외 판정을 수십~수천 건 반복하는 DH 작업이다.
> 해석 중심 연구의 사료비평을 대신하지 않는다.

선별 로그가 있어도 **언제 멈추고 무엇을 잠정으로 둘지**가 정해져 있지 않으면, 결과 수치는
형식만 갖춘 숫자가 된다. 아래 게이트는 그 멈춤 조건을 정한다. 하나라도 걸리면 다음 단계로
넘어가지 않고, 넘어갔다면 보고서에 그 사실을 적는다.

## 1. 판정은 비워 두되 채우지 않는다

- 판정이 빠졌거나 형식이 맞지 않는 건(기준 코드와 판정 불일치, 다른 묶음의 ID)은 `pending`으로
  남긴다. 기본값(포함 또는 제외)으로 메우지 않는다.
- `pending`이 0이 되기 전에는 건수·비율을 보고하지 않는다. 세션이 끊겨도 이미 받은 판정은
  병합하고 `pending`만 다시 돌린다(shard·resume, 전역 원칙 7).

## 2. 기준 확정 → pilot → 전체 실행

1. **기준 확정**: 연구질문에서 포함/제외 기준을 뽑아 사용자가 확인한다. 추론으로 채운 기준은
   `[제안]`으로 표시하고, 확인 전에는 한 건도 판정하지 않는다.
2. **seed 점검**: 사용자가 이미 적격이라고 아는 문헌·작품 3~5건을 미리 받는다.
   - 검색 결과에 seed가 **없으면** 검색식 문제다. 선별로는 되살릴 수 없으므로 검색부터 고친다.
   - pilot에서 seed가 **제외되면** 두 판정 사유를 읽고 기준 정의를 고친 뒤 같은 묶음으로 다시 돈다.
   - seed는 자기와 비슷한 건의 민감도만 보여 준다. 다른 유형이 빠지지 않았다는 증거는 아니다.
3. **pilot 대조**: 작은 묶음을 먼저 돌려 사용자(또는 연구팀)의 판정과 맞춰 본다. 사용자가
   통과시킨 건을 하나라도 놓쳤거나 pilot이 덜 끝났으면 **전체 실행을 시작하지 않는다.**
   사용자가 이를 무릅쓰고 진행하라고 하면 그 결정과 사유를 로그에 남기고 방법 서술에 적는다.

## 3. 두 판정자와 조정

- 가능하면 판정자 둘이 서로의 판정을 보지 않고 독립 판정하고, 갈린 건만 세 번째 판정(조정)으로
  보낸다. 판정자가 하나뿐이면(서브에이전트를 못 쓰는 환경 등) 단일 판정임을 보고서에 밝힌다.
- 일치도는 「포함·보류」 대 「제외」로 계산한다. 선별은 포함 비율이 몇 %에 그치는 일이 보통이라
  κ가 낮게 나와도 실제 일치는 높을 수 있다 — 관측 일치율·κ·PABAK를 건수와 함께 모두 적는다
  (보고 표준은 `quantitative-humanities.md`). 통계보다 **무엇에서 갈렸는지**를 먼저 읽는다.
  한 기준 코드에 충돌이 몰리면 그 기준이 두 가지로 읽히는 것이니 정의를 고치고 pilot을 다시 돈다.

## 4. 제외를 다시 본다

- 두 판정자가 모두 제외한 건에서 재현 가능한 무작위 표본(최소 20건, 기본 100건, 그보다 적으면
  전부)을 뽑아 상위 검토자가 다시 본다. 이 재검이 끝나기 전 수치는 **잠정**으로 표시한다.
- 핵심 기준어를 모두 담고 있는데 제외된 건(근접 제외)도 따로 모아 재검한다.
- 재검에서 제외가 뒤집히는 비율이 높으면 제외 판정 자체를 믿을 수 없다는 뜻이다. 패턴을 찾아
  기준을 고치고 해당 묶음을 다시 판정한다.

## 5. 기준이 바뀌면

- 선별 도중 기준을 바꾸면 개정 로그에 날짜·변경 내용·사유를 적고, 그 변경으로 판정이 뒤집힐 수
  있는 건을 다시 판정한다. **신구 기준을 섞은 판정을 조용히 합치지 않는다.**
- 산출 폴더를 덮어써야 하는 상황이면 새 폴더로 간다. 이미 판정이 있는 폴더를 덮으면 ID가 바뀐다.

## 6. 산출물

`output-contracts.md`의 JSONL 로그에 더해 다음을 남긴다.

| 산출물 | 내용 |
|---|---|
| 기준표 | 확정 기준, `[제안]` 해소 기록, 개정 로그 |
| 선별 로그 | 건별 판정자 A·B 판정, 조정 결과, 제외 사유 코드 |
| 흐름 수치 | 검색 → 중복 제거 → 제목·초록 → 전문 → 최종 포함의 건수(PRISMA 흐름 형식) |
| QC 기록 | seed 결과, pilot 대조, 제외 표본 재검 결과, 잠정/확정 여부 |
